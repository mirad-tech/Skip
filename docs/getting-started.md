# 快速开始

## 安装

下载并安装 [`Skip-v1.0.0-release.apk`](../downloads/Skip-v1.0.0-release.apk)。这是手动安装包，系统可能会提示确认未知来源应用。

## 首次启动

首次打开 Skip 时，先阅读应用用途、权限边界和风险说明。确认后再进入主流程。

## 开启无障碍服务

1. 在 Skip 中进入无障碍用途说明页。
2. 点击“去系统设置开启”。
3. 在 Android 无障碍设置中找到 Skip。
4. 手动开启服务，并确认系统提示。
5. 返回 Skip，确认服务状态已更新。

## 开始使用

开启服务后，进入“应用管理”选择目标 App。先使用默认规则观察运行结果，再按需要创建自定义规则或导入本地 JSON 规则包。

如果系统后台策略导致服务被关闭，请在系统设置中允许 Skip 后台运行，并在日志页检查最近的命中记录。

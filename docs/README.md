# Skip 文档

这里是 Skip 1.0.0 的公开使用文档入口。Skip 是一款本地运行的 Android 开屏页面辅助工具，只有在用户主动开启无障碍服务并启用规则后才会工作。

## 适用场景

- 想减少重复点击“跳过”“关闭”类低风险控件的手动操作。
- 希望规则、日志和诊断信息都保留在本机。
- 需要按应用分别管理规则和启用状态。

## 使用流程

1. 安装 Skip 1.0.0 APK。
2. 阅读首次启动披露内容。
3. 按应用内说明开启 Android 无障碍服务。
4. 在“应用管理”中选择目标 App。
5. 启用默认规则，或创建/导入本地规则。
6. 通过日志、统计和诊断包检查运行结果。

# Skip 使用文档

Skip 是一款本地运行的 Android 开屏页面辅助工具。它只在用户主动开启无障碍服务、完成用途说明并启用规则后工作，用于减少重复点击“跳过”“关闭”类低风险控件的手动操作。

当前版本：`1.0.7`

## 下载和安装

- [下载 Skip 1.0.7 release APK](https://github.com/mirad-tech/Skip/releases/download/v1.0.7/Skip-v1.0.7-release.apk)
- SHA256：`FEC5D817A278072298E2CA5DFBF8AA7CCB93949EEAFCBD128FA091CB0869D939`

这是手动安装的 Android APK，未上架应用商店。安装时如系统提示“未知来源应用”，需要用户自行确认是否继续安装。

## 首次启动

首次打开 Skip 时，先阅读应用用途、权限边界和风险说明。确认后再进入无障碍用途说明页。

开启服务流程：

1. 在 Skip 中进入无障碍用途说明页。
2. 点击“去系统设置开启”。
3. 在 Android 无障碍设置中找到 Skip。
4. 手动开启服务，并确认系统提示。
5. 返回 Skip，确认服务状态已更新。

## 应用管理和规则

Skip 支持为每个 App 单独管理规则状态。你可以在“应用管理”中查看目标 App，并分别控制默认规则、自定义规则和黑名单策略。

默认规则用于识别常见的“跳过”“关闭”类低风险控件。规则只在应用进入前台后的短时间窗口内生效，并受冷却时间、区域限制和安全策略约束。

自定义规则适合处理默认规则无法覆盖的场景。规则可以使用节点文字、内容描述和 View ID 关键词进行匹配，并支持 `contains`、`exact`、`regex` 三种匹配方式。

Skip 支持导入本地 JSON 规则包。导入时会检查包名、匹配条件、高风险词和坐标兜底限制；不符合安全边界的规则不会被直接使用。完整字段说明见 [`RULES_GUIDE.md`](../RULES_GUIDE.md)，示例见 [`sample_rules.json`](../sample_rules.json)。

## 日志、统计和诊断

点击日志记录规则命中、点击执行、失败、冷却、安全模式和安全策略阻止等阶段。它用于帮助用户判断规则是否生效，以及是否存在误命中风险。

统计页按应用和规则汇总命中、成功、失败、安全阻止和坐标兜底次数。建议先观察统计结果，再决定是否调整规则。

诊断包由用户主动导出，内容为本地 JSON 文件。它用于排查未命中、误命中、系统限制或多服务干扰等问题。导出诊断包前，请确认其中是否包含你不希望公开的应用名称、包名或日志片段。字段说明见 [`LOG_DIAGNOSTIC_GUIDE.md`](../LOG_DIAGNOSTIC_GUIDE.md)。

## 安全与隐私

Skip 默认在本机处理规则、日志、统计和诊断信息。联网仅用于你在关于页手动检测新版本和下载更新 APK，访问 GitHub Releases；不会上传屏幕内容、规则、日志、统计或个人数据。

- `INTERNET` 权限仅用于手动检测新版本和下载更新 APK。
- `REQUEST_INSTALL_PACKAGES` 仅用于下载更新 APK 后交给系统安装器。
- 不读取短信、联系人、相册、定位、相机、麦克风、电话或账号信息。
- 导入规则和导出诊断包通过系统文件选择器完成，不申请外部存储读写权限。
- 不 Root、不 Hook、不改包、不抓包、不注入。
- 不自动点击支付、授权、登录、注册、隐私同意、安装、删除、卸载、转账、发送、提交等高风险按钮。
- 命中高风险内容时，应用不会执行节点点击、手势点击或坐标兜底点击，只会记录安全日志。
- 坐标兜底默认关闭。只有在包名明确、锚点明确、冷却明确且符合低风险边界的规则中，才允许使用坐标兜底。

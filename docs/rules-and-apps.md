# 应用管理与规则

## 按应用管理

Skip 支持为每个 App 单独管理规则状态。你可以在“应用管理”中查看目标 App，并分别控制默认规则、自定义规则和黑名单策略。

## 默认规则

默认规则用于识别常见的“跳过”“关闭”类低风险控件。规则只在应用进入前台后的短时间窗口内生效，并受冷却时间、区域限制和安全策略约束。

## 自定义规则

自定义规则适合处理默认规则无法覆盖的场景。规则可以使用节点文字、内容描述和 View ID 关键词进行匹配，并支持 `contains`、`exact`、`regex` 三种匹配方式。

## JSON 导入

Skip 支持导入本地 JSON 规则包。导入时会检查包名、匹配条件、高风险词和坐标兜底限制；不符合安全边界的规则不会被直接使用。

完整字段说明见 [`RULES_GUIDE.md`](../RULES_GUIDE.md)，示例见 [`sample_rules.json`](../sample_rules.json)。

# 日志与诊断

## 点击日志

点击日志记录规则命中、点击执行、失败、冷却、安全模式和安全策略阻止等阶段。它用于帮助用户判断规则是否生效，以及是否存在误命中风险。

## 统计信息

统计页按应用和规则汇总命中、成功、失败、安全阻止和坐标兜底次数。建议先观察统计结果，再决定是否调整规则。

## 诊断包

诊断包由用户主动导出，内容为本地 JSON 文件。它用于排查未命中、误命中、系统限制或多服务干扰等问题。

导出诊断包前，请确认其中是否包含你不希望公开的应用名称、包名或日志片段。字段说明见 [`LOG_DIAGNOSTIC_GUIDE.md`](../LOG_DIAGNOSTIC_GUIDE.md)。

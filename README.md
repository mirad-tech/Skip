## 它是做什么的

很多 App 打开时会出现开屏页，上面有一个“跳过”“跳过广告”或“Skip”按钮。Skip 会在你主动开启无障碍服务后，尝试识别这些按钮并自动点击。

它会在普通 App 的开屏页尝试匹配跳过按钮。系统、支付、银行、输入法等敏感应用默认受保护；你也可以把不想处理的 App 加入黑名单。

## 怎么使用

1. 下载并安装 APK。
2. 打开 Skip。
3. 点击首页的“开启服务”。
4. 在系统无障碍设置里找到“开屏广告跳过助手”，手动开启。
5. 回到 Skip，进入“更多”。
6. 在“已安装应用”里选择目标 App，按需创建普通规则。
7. 重新打开目标 App，观察开屏页是否自动跳过。

如果你懂 JSON，也可以在“JSON 文件导入”里批量导入规则。

成功提示可以在“更多”里的“日志与隐私”中开关。

## 它安全吗

Skip 是一个本机辅助工具，不是破解广告工具。

它不会做这些事：

- 不 Root
- 不 Hook
- 不改包
- 不抓包
- 不后台截图
- 不隐藏图标
- 不强制保活
- 不上传屏幕内容
- 不读取短信、联系人、相册或定位

为了避免误触，Skip 默认不处理这些应用：

- 系统设置
- 应用安装器
- 支付类 App
- 银行类 App
- 钱包、金融、证券、保险类 App
- 密码管理器
- 输入法

## 为什么需要无障碍权限

Android 不允许普通 App 直接操作其他 App 的界面。Skip 只能通过系统提供的无障碍服务读取界面节点，并在满足规则时执行点击。

这个权限需要你手动开启，也可以随时在系统设置里关闭。

## 会记录什么

Skip 只在本地记录简单点击日志：

- 时间
- App 包名
- 命中的关键词或规则名

不会记录完整屏幕内容，也不会上传日志。

## 常见问题

### 为什么有些 App 不生效？

可能有几个原因：

- 目标 App 已加入黑名单
- 开屏按钮不是标准无障碍节点
- 按钮文案或控件 ID 没有命中规则
- 当前 App 属于默认保护类型
- 开屏页出现时间太晚，超过了自动检测窗口

### 为什么有安全保护？

因为自动点击有误触风险。敏感应用和系统界面默认避开，黑名单也会关闭默认跳过。

### 这是正式版吗？

当前版本能完成基础自动跳过、规则管理、安全保护和点击日志，规则覆盖还会继续改。

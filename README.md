# Skip

Skip 是一个本地运行的 Android 自动点击辅助工具 / 开屏页面助手。它只在用户主动开启无障碍服务、启用应用和规则后，在应用打开后的短时间窗口内辅助点击明确的“跳过”“关闭”类低风险控件。

当前版本：`1.4.0`

## 产品边界

- 不宣传为广告破解、广告屏蔽或绕过工具。
- 不复制、不逆向、不照搬李跳跳或其他同类产品代码。
- 默认本地处理，不联网，不上传屏幕内容、规则、日志、统计或个人数据。
- 不接入广告 SDK、统计 SDK、联网 SDK。
- 不自动点击支付、授权、登录、注册、隐私同意、安装、删除、转账、发送、提交等高风险按钮。

## 功能

- 首次启动披露：用户阅读并主动同意后，才会进入无障碍用途说明。
- 无障碍用途说明：进入系统设置前解释读取窗口内容、执行手势、报告 View ID 的用途。
- 按应用控制：每个 App 可单独开启/关闭本应用自动辅助，也可分别控制默认规则和自定义规则。
- 规则管理：支持本地创建、启用、停用、编辑、删除规则。
- 规则导入：支持本地 JSON 文件导入，并校验包名、匹配条件、高风险词和坐标兜底限制。
- 命中日志：记录命中、点击、失败、冷却、安全模式和安全策略阻止。
- 诊断包导出：用户复现问题后可主动导出本地 JSON 诊断包，用于分析未跳过、误跳过、系统限制和安全阻止原因。
- 命中统计：按应用和规则统计命中、成功、失败、安全阻止、坐标兜底次数。
- 坐标兜底：默认关闭，仅允许用户手动创建或导入的低风险规则使用。

## 使用

1. 安装 APK 并打开 Skip。
2. 阅读首次启动披露页。
3. 主动勾选同意后，查看无障碍权限用途说明。
4. 点击“去系统设置开启”，在系统无障碍设置中手动开启 Skip。
5. 回到 Skip，在“应用管理”中选择目标 App，按需切换默认规则和自定义规则。
6. 需要更精确匹配时，创建本地规则或导入 JSON 规则。
7. 在“日志与隐私”中查看点击日志、规则日志、命中统计、隐私说明和权限说明。

## 高风险点击保护

默认禁止自动点击包含以下含义的按钮或节点：

`同意`、`授权`、`允许`、`支付`、`购买`、`确认支付`、`登录`、`注册`、`隐私政策`、`用户协议`、`安装`、`删除`、`卸载`、`转账`、`发送`、`提交`

命中后行为：

- 不执行 `ACTION_CLICK`。
- 不执行手势点击。
- 不执行坐标兜底点击。
- 只写入安全日志。
- 日志原因标记为 `blocked_by_safety_policy`。

## 坐标兜底限制

坐标兜底默认关闭，并且必须同时满足：

- 只能用于用户手动创建或主动导入的规则。
- 必须绑定具体包名。
- 必须限制在应用启动后的时间窗口内。
- 必须有锚点规则。
- 必须有点击冷却时间。
- 必须通过高风险点击保护策略。
- 不允许用于支付、授权、登录、隐私同意等场景。

## 规则 JSON

导入文件使用本地 JSON，不联网订阅。格式说明见 [RULES_GUIDE.md](RULES_GUIDE.md)，示例见 [sample_rules.json](sample_rules.json)。

Skip 会拒绝为自身包名导入自动点击规则。受保护应用即使被导入策略或规则，也不会执行自动点击。

## 隐私与权限

Skip 保持本地处理：

- 不申请 `INTERNET` 权限。
- 不读取短信、联系人、相册、定位、相机、麦克风、电话、账号。
- 不申请外部存储读写权限，导入导出使用系统文件选择器。
- 不 Root、不 Hook、不改包、不抓包、不注入。
- 日志只保存在本机，并对可能包含隐私的信息做最小化记录和脱敏。
- 诊断包只由用户主动导出，不自动上传；字段说明见 [LOG_DIAGNOSTIC_GUIDE.md](LOG_DIAGNOSTIC_GUIDE.md)。

默认保护范围包括系统界面、桌面、安装器、权限页、输入法、支付、银行、钱包、金融、密码管理等敏感场景。

```powershell
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:assembleDebug
git diff --check
.\gradlew.bat :app:assembleRelease
```

release 构建需要本地 `keystore.properties` 和签名文件。真实签名文件、密码和密钥不得提交到仓库。
